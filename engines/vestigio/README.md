# VESTIGIO

VESTIGIO es el motor 3D del repositorio. Su código nativo, Studio, pruebas y
recursos pertenecen a esta carpeta. Las herramientas comunes de preparación y
los scripts estables siguen en `../../tools/`.

Desde la raíz del repositorio:

```powershell
./tools/build.ps1 -Engine Vestigio -Preset debug -Test
./tools/run-3d-demo.ps1
./tools/run-studio-3d.ps1
```

La guía de uso está en `../../VESTIGIO-COMO-USAR.md`.
