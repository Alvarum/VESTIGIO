# 05 — Procedencia y decisiones de reutilización

Fecha de consulta: 2026-09-20. **No se incorporó código ni contenido de referencia a VESTIGIO durante esta investigación.** Las copias temporales son material de lectura, no dependencias vendorizadas. El [índice](sources-index.md) registra archivos y hashes; [manifest JSON](source-manifest.json) conserva URLs/revisiones.

`THIRD_PARTY.md` declara que la licencia del código propio de VESTIGIO no está elegida; no hay LICENSE raíz en el baseline. Por ello no puede certificarse compatibilidad con una licencia futura desconocida. Para favorecer juegos externos abiertos o cerrados, se recomienda evaluar MIT/zlib para el SDK propio; la elección corresponde al titular y no se altera aquí.

Las licencias se registran desde textos observados. Esto no certifica una redistribución futura. El criterio operativo es concreto: no incorporar material E hasta documentar archivo/revisión/titular/licencia, cambios, avisos distribuidos y compatibilidad con la licencia elegida de VESTIGIO. Una implementación propia debe partir del concepto y contrato, no ser una traducción línea a línea.

Se consultan para diseñar contratos; no se copian ejemplos de código.
