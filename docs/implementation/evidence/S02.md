# S02 — Controlador y movimiento con colisión

Estado: **INTEGRATED**, revisado por el usuario el 2026-09-27. Confirmó que el recorrido con colisiones funciona correctamente y autorizó continuar a E01. Commit de implementación y pruebas: `22e937a2d589e256f38ff7268603c26723343cae`.

El controlador público `vestigio/controller.h` mueve un volumen vertical que aproxima una cápsula mediante esferas solapadas. Recibe ticks de simulación fijos, aplica gravedad, salto, suelo, pared, techo, pendiente y escalón, y rechaza una posición inicial penetrada con `VG_ERROR_CONFLICT`. Una consulta de segmento permite a un seguidor de waypoints comprobar alcance directo con las mismas restricciones; no calcula rutas ni usa navmesh. La escena Player ahora incluye suelo, monumento, escalón y pasillo con colliders, renderizados en GPU. WASD mueve, ratón mira, Espacio salta, F3 alterna el overlay y Escape cierra.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-3d-demo.ps1
```

Camina hacia los objetos: no debes atravesarlos. Usa Espacio para saltar y F3 para ver las formas de colisión verdes. Para repetir el recorrido automatizado:

```powershell

```

Límites: el volumen es una aproximación de cápsula, no una cápsula matemática exacta; sólo hay plataformas estáticas; no hay navmesh, plataformas móviles ni dinámica de cuerpos rígidos. La consulta directa de waypoint se limita a 20 unidades y 2048 ticks.
