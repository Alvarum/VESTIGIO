# M01 — Importación GLB/glTF estática a representación propia

Estado: **INTEGRATED**  
Commit integrado: `656fda7`

## Resultado

- cgltf 1.15 quedó vendorizado como dependencia privada con licencia, procedencia y SHA-256 registrados.
- El importador CPU produce una IR propia empaquetada para nodos, jerarquía, mallas, primitivas, vértices, materiales, texturas, imágenes y dependencias.
- glTF Y-up se convierte a VESTIGIO Z-up sin recenter de pivotes. Se conservan matrices locales, raíces de escena y signo del determinante.
- Se admiten GLB, glTF embebido/externo, indexado/no indexado y normales planas deterministas cuando faltan.
- URI, base64, accesores, límites, finitud, extensiones requeridas y OOM se validan antes de publicar salida.
- El fingerprint incluye dominio/versión/opciones, fuente completa y cada dependencia con path, tamaño y hash.

El workspace de cgltf usa una arena acotada para no depender del comportamiento parcial del parser ante OOM. En GLB se dimensiona por el chunk JSON validado, no por el payload BIN; una regresión sintética de 8 MiB funciona con 128 KiB de workspace.
