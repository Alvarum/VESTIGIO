# Oleada 7 — ambiente y puerta con audio

Estado: **entregable hobby implementado y probado en dispositivo real; escucha del usuario pendiente**. A01 queda `IN_PROGRESS`: esta entrega conecta el Atrium audible, pero no constituye el sistema completo de audio de proyecto descrito por el ticket.

El Atrium reproduce un ambiente original en loop mediante MusicStream y un efecto corto al activar la puerta con **E**. Player y Studio **Probar** usan el mismo núcleo: Sound compartido y voces independientes para los efectos, eventos de puerta deduplicados, posición del oyente desde la cámara y volumen espacial. Studio **Editar** permanece en silencio; Detener libera stream, voces y dispositivo. El foco pausa y reanuda el audio. Hay cuatro volúmenes (general, música, efectos, ambiente) persistentes en el mismo archivo de ajustes visuales. Player permite subir/bajar el general con **F8/F7**; Studio ofrece cuatro controles deslizantes. La ausencia de dispositivo o de un WAV produce diagnóstico y no impide jugar.

Los WAV son originales y reproducibles con `python tools/generate-demo-audio.py`: [procedencia y formato](../../../assets/demo/audio/README.txt). No se les asignó una licencia nueva; la decisión general del proyecto sigue pendiente.

## Para probar

Desde la raíz del repositorio, después de `tools/bootstrap.ps1`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-3d-demo.ps1
```

Escucha el ambiente **al menos ocho segundos** para cubrir dos ciclos. Acércate a la puerta naranja y pulsa **E**: debe sonar una vez por interacción, localizado hacia la puerta. Mueve la cámara/jugador y comprueba el cambio de dirección/volumen. Alterna a otra ventana y vuelve; el audio debe pausarse con el foco. Usa **F7/F8** para bajar/subir volumen general, cierra con Escape y abre de nuevo para comprobar que se recordó.

Para una prueba automatizada que no modifica tus preferencias normales:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-3d-demo.ps1 -SmokeDoor -SmokeAudio -Settings build/w07-audio.settings
```

En Studio, ejecuta `tools/run-studio-3d.ps1`, ajusta **General**, **Ambiente** y **Efectos**; entra a **Probar** y abre la puerta con E. Pulsa **Detener**: debe callar. Vuelve a abrir Studio para comprobar los deslizantes guardados. Para usar preferencias aisladas, añade `-Settings build/mi-audio.settings` al script.

Límites: el ambiente de 4 segundos usa un stream de decodificación con el WAV codificado retenido en memoria para soportar rutas Unicode; todavía no se prueban canciones largas desde disco ni un catálogo general de recursos/emisores definido por el documento. Music y efectos comparten controles de bus, pero Studio aún no permite asignar pistas o WAV arbitrarios. No hay afirmación de calidad auditiva final, de spatialización binaural ni de A01 formal completo. Se detiene el trabajo tras esta oleada hasta nuevo encargo.
