# G01 — Primer frame de geometría GPU

Fecha: 2026-09-20. Base integrada: `2052e5b4d69f8ae169df073f3ed8a761b80c62dc`.

## Resultado implementado

- `vestigio_gpu_raylib`: backend privado sobre raylib/rlgl OpenGL 3.3, separado de `retro_core` y del renderer software.
- Mesh cúbico subido a VAO/VBO, shader GLSL 330 compilado, material y billboard texturado con alpha; cámara Z-up y depth buffer.
- RenderTexture GPU configurable 320×180/640×360 y presentación point/integer con letterbox directamente desde textura GPU.
- Contadores frame/draws/triangles/uploads/readbacks/VRAM propia estimada. El frame normal no llama lectura de pixels; `capture` es una operación explícita y contabilizada.
- Consulta de `GL_VENDOR`, `GL_RENDERER`, `GL_VERSION` mediante el loader de funciones de rlgl, sin incluir headers Win32/OpenGL conflictivos.
- Compilación candidata de shader: un shader inválido se rechaza con error y el renderer principal continúa funcionando.

El backend contiene una escena diagnóstica acotada para este spike; todavía no consume World/SDK ni reemplaza el Player. Eso pertenece a R01/R03/G03/G04.
