Estado: **INTEGRATED**. Commit de implementación: `7efc54c`.

## Resultado

`vestigio_player` abre Atrium, una escena original con suelo, monumento y pilares instanciados desde [atrium.gltf](../../../assets/demo/atrium.gltf). La lógica de juego en `src/player/demo_scene.c` usa sólo `vestigio/vestigio.h`: crea el mundo y la cámara, adquiere el modelo, registra renderables y procesa acciones de movimiento y mirada. El host raylib/OpenGL conecta ventana, input, SDK y renderer GPU. WASD y ratón permiten recorrido libre; Escape o cerrar la ventana sale. No hay colisiones, salto ni editor.

Arranque desde la raíz del repositorio, después de `tools/bootstrap.ps1`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-3d-demo.ps1
```

Para una prueba automática con captura:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-3d-demo.ps1 -Smoke 8 -Capture build/atrium.png
```

El ejecutable resuelve el asset junto a sí mismo; no depende del directorio de trabajo. El smoke inyecta movimiento y giro, redimensiona la ventana y comprueba draw calls, upload, ausencia de readback durante frames normales y desplazamiento de la cámara. La captura solicitada hace un único readback.
