# D02 — Documento nativo, transacciones y Tool API

Estado: **INTEGRATED**  
Commit integrado: `2e15e5e`

## Resultado

- El documento nativo conserva un DOM canónico versionado, campos opcionales desconocidos y referencias de assets sin copiar blobs CPU/GPU al historial.
- La Tool API aplica lotes tipados con `expected_revision`, IDs temporales deterministas, remapeo de referencias al duplicar, validación, preview y commit atómico.
- Undo y redo conservan el documento y sus colas ante validación fallida u OOM.
- El guardado usa temporal, backup y journal recuperable; protege documentos de versión futura y respaldos huérfanos en vez de sobrescribirlos.
- El instanciador construye un `VgWorld` candidato completo con mapa UUID→entidad, TRS, padres, cámaras y leases de `AssetId` resueltos por callback.
- Un fallo de entidad, jerarquía, cámara o asset destruye el candidato, libera leases y deja el output del llamador intacto.
