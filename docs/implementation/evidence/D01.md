## Resultado

- Se añadió un parser JSON C11 estricto, con UTF-8 validado, claves únicas, números finitos y diagnóstico con ruta.
- Los documentos `project` y `level` v1 validan versión, UUID, referencias, ciclos de padre, TRS, environment, sectores/portales legacy y los componentes iniciales.
- Los campos opcionales desconocidos sobreviven el round-trip; las capacidades requeridas desconocidas se rechazan.
- El escritor canónico ordena claves de objeto en `O(n log n)` y conserva el orden de arrays y los lexemas numéricos.
- La salida es transaccional: un error no publica documento ni buffer parcial.
