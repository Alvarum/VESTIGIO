# G03 — Renderables y materiales GPU compartidos desde SDK

Estado: **INTEGRATED**
Commit integrado: `50ece2a`

## Resultado

- El SDK público expone componentes versionados de malla y sprite por entidad. El mundo conserva referencias propias a assets y los getters entregan leases liberables.
- El registro conecta la IR glTF/GLB con el backend GPU sin exponer tokens privados. Cien entidades comparten una sola residencia y un solo upload del modelo.
- `vg_gpu_renderer_draw_world` selecciona cámara, extrae transforms y bounds mundiales, hace culling y dibuja materiales opaque, mask y blend, sprites, wireframe y material de error.
- El orden transparente es estable de atrás hacia delante. El winding respeta transforms con determinante negativo.
- Reload fallido conserva la versión GPU publicada. Destruir 99 de 100 instancias no libera el recurso compartido; destruir el mundo y purgar sí lo libera.
- Recrear el backend mediante detach/attach programa exactamente un reupload para recursos aún retenidos. Un renderer que no pertenece al contexto se rechaza con `VG_ERROR_CONFLICT`.
- El consumidor C11 instalado carga un glTF embebido, crea 100 componentes y valida referencias, reload conservador, destrucción parcial y purge desde un prefijo externo al repositorio.
