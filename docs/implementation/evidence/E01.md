# E01 — Studio 3D con Editar / Probar

Estado: **INTEGRATED**, revisión interactiva del usuario pendiente. Implementación y pruebas: `73fe637`.

Studio abre `assets/demo/atrium.level.json` como documento nativo `vestigio.level`, instancia su cámara, modelo y colliders mediante el runtime/SDK C y presenta el mundo en un `HwndHost` OpenGL. La cámara editorial ofrece libre, órbita, ortográfica y encuadre; el clic selecciona por UUID con máscaras editoriales para mallas, luces, cámaras y triggers. **Probar** crea un mundo separado desde el mismo documento y usa el controlador con colisiones de S02. **Detener** destruye esa instancia y vuelve a la cámara de Editar. El archivo, su revisión y su contenido no cambian por navegar, seleccionar ni jugar. El arranque `--atrium` es independiente de proyectos `.retro` anteriores.

## Para probar

Desde la raíz del repositorio, después de `tools/bootstrap.ps1`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-studio-3d.ps1
```

Debe abrirse **Atrium 3D**. En Editar: clic izquierdo selecciona un objeto, clic derecho y arrastre gira la vista, WASD desplaza, Espacio/Ctrl suben y bajan. Cambia entre cámara libre, órbita y ortográfica; selecciona un objeto y pulsa **Encuadrar selección**. Pulsa **Probar**, mueve con WASD, mira con el ratón y salta con Espacio; la colisión debe impedir atravesar suelo y pilares. Pulsa **Detener**: vuelve la cámara editorial y la selección. Cierra la ventana para salir. `-NoLaunch` sólo prepara y compila, sin abrir la aplicación.

Límites de esta oleada: `--level` acepta otro documento, pero el resolver GPU sólo reconoce el AssetId/modelo del Atrium; no es importación genérica. Luces, cámaras y triggers usan volúmenes editoriales sintéticos para picking. Player conserva su composición Atrium en código y Studio carga el archivo nativo: comparten modelo, runtime y escena visual, pero la fuente documental única para ambos se abordará cuando el flujo de autoría lo necesite. Todavía no hay gizmos, transformaciones, guardado desde Studio ni round-trip editorial; son E02/E03. La verificación automática no sustituye la revisión visual e interactiva de la ventana completa por el usuario.
