VESTIGIO demo audio provenance

atrium-ambience.wav and door-move.wav are original procedural sounds generated
by tools/generate-demo-audio.py. They contain no recordings, sample libraries,
or other third-party audio. Usage rights for the project remain to be decided
by its owner; this file does not grant a license.

Regenerate from the repository root with:
    python tools/generate-demo-audio.py

Format: mono, 16-bit PCM WAV, 22050 Hz. The ambience is a seamless four-second
loop; the door event lasts about 0.7 seconds.
